# Ausnahmeliste der Zeilen-Obergrenze 3000 (FILE-SIZE-CEILING-3K-83).
#
# Format (wie scripts/file_size_baseline.txt): <max-zeilen> <pfad>  # <Begruendung/Historie>
#
# Regel: eine Datei OHNE Eintrag muss <= 3000 Zeilen haben (harte Grenze,
# dauerhaft). Eine Datei MIT Eintrag darf ihren Eintrag nicht ueberschreiten.
# Der Wert darf NUR sinken; faellt die Datei auf <= 3000 Zeilen, faellt ihr
# Eintrag weg (die harte Grenze gilt dann dauerhaft). Ein NEUER Eintrag traegt
# den IST-Wert der Datei. Jede Aenderung an dieser Datei ist ein sichtbares
# Ereignis (Diff) und wird reviewt.
#
# ACHTUNG 500er-Ratchet: der 500-Zeilen-Ratchet (scripts/check_file_sizes.sh,
# Population nur crates/) kennt diese Liste nicht. Ein neues Modul mit mehr als
# 500 Zeilen braucht ZUSAETZLICH einen Eintrag in scripts/file_size_baseline.txt
# (sonst fast-2-Rot); unter agent-harness/ gilt nur die 3000er-Obergrenze
# dieser Liste, weil der 500er-Ratchet das Harness nicht abdeckt.
#
# Eigentuemervorgabe 2026-10-20: „Auf Dauer waere unter 3k Zellen pro File
# wahrscheinlich sinnvoll" und „wenn einmal eine Datei unter der Grenze ist,
# dann darf sie nie mehr darueber sein". SOLL-Zielsemantik:
# feature/quality/file-size-policy.md. Gate: scripts/check_file_ceiling.sh.
#
